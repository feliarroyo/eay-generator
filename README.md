# EAY Generator

Tool for creating custom prompt episodes for the Enough About You mode in Fibbage 3 and 4. Made using Python and PySide6.

## Features planned

- Create new episodes with custom prompts for the mode that's all about the players.
- The episodes created are game-agnostic: compatible with either game.
- Choose whether to play with custom-made prompts only or mix them up with the base game's prompts.
- You can choose to add audio to any of your prompts. However, if no audio is inserted, a silent audio file will be generated with duration adjusted to the length of the prompt text.
- Once you link your game's installation folder, you can install the episodes to your game with a single click, as well as revert the changes at any time.
