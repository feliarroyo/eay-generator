Tool for creating custom prompt episodes for the Enough About You mode in Fibbage 3 and 4. 

Built using Python and PySide6.

## Features

- Create new episodes with custom prompts for the mode that's all about the players.
- The episodes created are game-agnostic: instantly compatible with both Fibbage 3 and Fibbage 4.
- Choose whether to play with custom-made prompts only or mix them up with the base game's prompts.
- You can choose to add audio to any of your prompts if you want to (the game will still work even if no audio file is found for a prompt).
- Once you link your game's installation folder, you can install the episodes to your game with a single click.
- Multi-language UI support (English and Spanish as of right now)

## Instalation

1. Go to [Releases](https://github.com/feliarroyo/eay-generator/releases) and download the zip file for the latest version.
2. Extract its contents and run the .exe file contained within.

## Quick Start

1. Open the application and click **Create New Episode** to start adding your custom prompts.
2. When you are finished, click on **Save Episode**, and then **Return to Main Menu**.
3. Go to **Apply Custom Episodes**, and choose your game folder (either Party Pack 4 or 9) after clicking **Select Party Pack Folder**.
4. Select the game you want to install the files on and choose the episode(s) you want to install (as well as if you want to keep the base prompts).
5. Finally, click on **Generate And Install on Game Pack** to insert the custom prompts into your installed game.
